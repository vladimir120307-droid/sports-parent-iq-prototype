# Sports Parent IQ: Clickable Prototype

A prototype of a mobile-first personality quiz: sample questions, scoring, ten result types, a share card, a challenge link and email capture after the result.

Questions, scores and result text all live in one `QUIZ` object at the top of the script, so they can change without touching the code. Copy and artwork are placeholders, and nothing typed into the page is stored or sent.

Try it: https://vladimir120307-droid.github.io/sports-parent-iq-prototype/

## Game Day: the playable 3D version

The same quiz as a game you play from the sideline: five moments across one Saturday, a 15-second shot clock, a crowd that reacts to every answer, a yellow card when you lose it, and a stadium reveal that ends with your player card. Built with three.js: real-time floodlights and sun with shadows, bloom, an instanced crowd of about a thousand fans, characters and every other model made in code, and a rear-view mirror that is a second camera pointed at the back seat. Sound is synthesized with Web Audio, so there are no audio files. Devices without WebGL get a 2D version of the same game.

Play it: https://vladimir120307-droid.github.io/sports-parent-iq-prototype/game/
